Verslagje van 2G op verplaatsing! Beide dames doen het uitstekend: Sylvie rijfde al 10 klassementpunten binnen, Béa 11. Beiden erg dicht bij een verhoging!

Afgelopen zondag zakten 2G af naar Puyenbroeck om het daar op te nemen tegen een B2, 2 C1 en C2.
Tja, sterk klassement, maar we gingen het beste ervan maken (we hadden 3 C2 bij en 3 D)

Dubbel dames Béa en Lieve, 1ste set zat niet goed, 2de set was beter en 3de set gingen ze nipt onderuit.
Dubbel heren Bert en Wim, 1ste set zat niet goed en 2de set idem dito.
Enkel Geert, 1ste set was Geert goed mee tegen de B2-speler, maar moest op het einde lossen, 2de set was er teveel aan.
Enkel Bert, 1ste set gemakkelijk gewonnen, 2de set herpakte tegenstander hem, maar Bert gaf hem geen kans.
Enkel Béa, zowel 1ste set als 2de set won Béa vrij gemakkelijk tegen haar C1-dame
Enkel Sylvie, 1ste set zeer nipte overwinning met 21-23, halfdood aan de 2de set beginnen en denken aan de 3 puntjes die ik eventueel kon binnenhalen (t was tegen C1-dame) en dan vrij gemakkelijk 2de set binnenhalen.
Voorlopig tussenstand 3-3, alles hangt af van de mixen.
Mix 1 Lieve en Geert, 1ste set verloren ze, 2de set serieuze herpakking en nipt verloren met 22-20.
Mix 2 Sylvie en Wim, 1ste set gewonnen, 2de set verloren, eventjes overleggen of we nu ook ons hersenen moeten gebruiken of niet, 3de set hebben we voor de andere spelers mooi afgesloten met een nipte overwinning 20-22.

De ploegkapitein was en is trots op haar ploeg!

\- Sylvie -
