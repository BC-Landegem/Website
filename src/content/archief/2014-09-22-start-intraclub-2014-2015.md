Nu woensdag start de eerste speeldag van een nieuwe jaargang intraclub! Graag allemaal aanwezig ten laatste om **20u15** (Of kwartiertje later **indien je mij op tijd verwittigt**), zodat de prijsuitreiking ook voor de jeugd vroeg genoeg kan doorgaan.

Dit seizoen komen er enkelen nieuwigheden:

\- Iedereen start met hetzelfde basispunt

\- De jeugdreeks verdwijnt (ze zijn té goed :) ) en we lanceren een veteranenranking!

Er wordt geloot volgens de einduitslag van vorig seizoen: [Dees](intraclub)!

Tot dan!
